# 프런트엔드 시작 프로젝트 구성

사용자 요청: SEMOSAN_FE와 비슷하게 역할별·기능별 파일을 갖춘 웹 프런트엔드 프로젝트를 구성한다.

- [x] React·TypeScript·Vite 개발 설정과 품질 검사 명령 구성
- [x] app/components/features/hooks/lib/types 등 책임별 파일 구성
- [x] 가상 데이터 기반 검수 목록·상세와 공통 메뉴 연결
- [x] 기존 기획 문서를 archive로 보관하고 현재 README 작성
- [x] 의존성 설치, 타입 검사·린트·빌드 검증 후 지정 폴더에 반영

범위: 개발 시작용 뼈대. 서버, AI, 장비 제어, 실제 검수 결과 저장은 포함하지 않는다.
검증: 검색·라우팅·없는 ID 처리의 구조 확인, 타입 검사·린트·프로덕션 빌드. 실제 브라우저·실서버 검증은 별도로 명시한다.

검증 결과: npm run build(타입 검사 포함), npm run lint 통과. 브라우저에서 실제 조작하는 검증은 수행하지 않음.
