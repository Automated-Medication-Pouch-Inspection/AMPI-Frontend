# SaaS Medilux

AI 기반 ATDPS 후장착 약품 자동검수 시스템의 웹 개발 준비 문서입니다.

현재 단계는 **구성 제안**입니다. 실행 가능한 웹앱, AI 모델, 장비 연동, 로그인·서버는 아직 구현하지 않았습니다. 아래 기능과 기술은 기존 확정 명세가 없는 상태에서 작성한 제안이며, 사용자의 실제 업무 흐름에 맞춰 조정해야 합니다.

## 제안 기술

- 개발 언어: TypeScript
- 화면: React
- 개발·빌드 도구: Vite
- 화면 이동: React Router
- 초기 데이터: 가상 데이터와 교체 가능한 API 계층
- 서버 데이터 관리: 실제 API 연동 시 TanStack Query 도입 검토
- 스타일: 먼저 공통 색상·간격·글자 크기를 정의하고 UI 라이브러리는 구현 시 선택

기술 선택은 제안입니다. 라이브러리를 설치할 때 공식 문서에서 호환 버전을 확인하고 잠금 파일을 함께 관리합니다.

## ChatGPT 프로젝트 소스로 사용할 때

우선 `01-project-brief.md`, `02-file-structure.md`, `03-frontend-guidelines.md`, `open-source-references.md`를 업로드합니다. 프로젝트 지침에는 다음 문장을 추가할 수 있습니다.

> 첨부된 Medilux 프로젝트 문서를 기준으로 웹앱을 설계·구현·검토한다. 확정 요구사항과 제안을 구별하고, 기존 코드와 사용자 요구사항을 우선한다. 외부 자료는 참고 기준으로 사용하고 실제 기술과 업무에 맞게 적용한다.

로컬 폴더에 문서를 저장하는 것과 ChatGPT 프로젝트의 소스에 업로드하는 것은 별도 작업입니다. 이 폴더의 문서는 외부 원문을 요약·해석한 자체 문서이며, 외부 지침 전체나 앱 소스코드를 복제하지 않았습니다.
