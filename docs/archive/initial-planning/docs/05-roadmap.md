# 개발 순서 제안

## 1. 화면 흐름 확인

- 가상 데이터로 검수 목록과 상세 화면을 만든다.
- 실제 ATDPS 검수 단위와 담당자 판단 흐름을 확인한다.
- 이미지, 기대 정보, AI 결과, 검토 폼의 배치를 검토한다.
- React + Vite 또는 Next.js 중 기술 구성을 확정한다.

완료 기준: 가상 검수 한 건을 열고 검토 결과를 기록하는 흐름을 시연할 수 있다. 가상 저장임을 표시한다.

## 2. 웹 시제품 보강

- 약품 검색, 상태 필터, 변경 이력 화면을 추가한다.
- 오류·빈 상태·로딩·키보드 접근을 점검한다.
- 핵심 검수 흐름에 필요한 자동 검증을 추가한다.

완료 기준: 시연에 필요한 화면과 예외 상태를 검토할 수 있다. 운영 가능한 시스템으로 표현하지 않는다.

## 3. 서버와 계정 연동

- 실제 인증과 기관·역할별 권한을 서버에 구현한다.
- 데이터 저장, 동시 수정 처리, 변경 이력을 연결한다.
- 가상 API를 실제 API로 교체한다.

완료 기준: 권한이 없는 데이터 접근이 서버에서 차단되고, 저장 실패·중복 제출·동시 수정이 검증된다.

## 4. AI와 장비 연결

- 장비·카메라 사양과 전송 형식을 확정한다.
- 모델 버전·분석 실패·재처리 흐름을 구현한다.
- 실제 이미지와 현장 조건으로 성능 및 업무 적합성을 검증한다.

완료 기준: 화면 시연과 실제 분석 결과를 구별하고 현장 평가 결과를 기록한다. 승인 기준과 운영 책임은 실제 업무 담당자와 별도로 확정한다.

## 5. SaaS 운영 준비

기관 분리, 계정 운영, 백업·복구, 배포, 모니터링, 보존 기간을 정의한다. 과금·구독은 필요한 경우에만 추가한다. 각 단계의 일정은 미정이다.
